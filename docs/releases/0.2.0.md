# Slopbox 0.2.0

- Generic command launch with host-selected executables, application bundles and dependency discovery on Linux and native macOS. No harness adapter is required for ordinary execution.
- Host-configured default commands and guest environment values, plus persistent per-workspace application state. macOS account credentials can be resolved directly from host Keychain.
- Reusable account/signing defaults and directory rules, preserving exact-workspace restrictions and repository policy ceilings.
- Opt-in HTTPS account mediation through explicit session trust, including the ordinary proxy. Other destinations still require approval; authentication remains host-side.
- Linux runtimes work with non-NixOS Nix installations or an explicit Nix-free runtime. Native macOS supports Mach-O library closures and read-only application resources.
- Native startup tolerates bounded launchd delays, and PTY cleanup closes the terminal before waiting for child teardown.

## Compatibility and boundaries

Existing legacy Pi configuration remains supported. The embedded integration is migration debt, not the interface required for new agents.

Generic subprocesses share the agent's attached account/model authority. They do not automatically receive the legacy Pi integration's separate tool role. Selecting a generic runtime does not inherit the active host development environment or activate a project flake; declare runtime resources and client environment explicitly.

Bundles expose their entire selected tree read-only. Dependency roots authorize discovered files, not whole directories. Neither imports host credentials, dotfiles or package caches implicitly. Keep unrelated data out of bundles and installations stable during execution.

Native macOS remains experimental, with local acceptance on Apple silicon/macOS 27. Named application IPC, generic native restricted tool roles, and native staged workspaces remain unavailable. Clients must honor the configured transport and trust; certificate-pinned clients and chunked request uploads are not supported by account TLS mediation.

Unmodified Pi and Claude have local native OpenRouter/Haiku acceptance; Aider and Claude have Linux fixture coverage. This is not a guarantee that every agent or provider feature works. Live inference tests are opt-in, provider-capped and excluded from CI.

## Installation

The public Homebrew package is for Apple silicon macOS:

```sh
brew update
brew install pprotas/tap/slopbox  # or: brew upgrade pprotas/tap/slopbox
```

Configure tools, accounts and client settings in the host `~/.config/slopbox/config.toml`; see [configuration](../configuration.md) and the [native runtime example](../poc-native-runtime.md#application-example). Upgrading does not migrate host logins or silently authorize resources. A rebuilt executable may require fresh Keychain approval.

Linux installation remains available through the Nix package or a source build with the required runtime dependencies. See [platforms](../platforms.md).
